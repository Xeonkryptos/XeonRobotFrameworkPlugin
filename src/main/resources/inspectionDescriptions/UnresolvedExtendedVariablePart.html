Reports parts of the extended variable syntax, e.g. ${OBJECT.attribute.method()}, which cannot be resolved: the variable itself or an attribute, property or method of the object it is accessed on.

Example:


*** Test Cases ***
My Test
    ${person} =    Create Person
    Log    ${person.name}       # resolved
    Log    ${person.unknown}    # will be marked as unresolved

Text after this comment will only be shown in the settings of the inspection.

The type of the object is inferred from the Python type of the variable: the return type of the keyword it is assigned from, the value of a user keyword returned with [Return] or RETURN, a data type conversion or a variable of a Python variable file. When the type can not be inferred, every part accessed on the object is reported. Only the first unresolved part of an expression is reported, because all following parts depend on it. Parts behind a nested variable are not checked.
