Reports user-defined keywords that combine embedded arguments in the keyword name with an explicit [Arguments] setting when the configured Robot Framework version does not support this syntax.

This inspection checks each user keyword declaration and flags it when both argument styles are used together. The combination is only valid starting with Robot Framework 6.1.

Examples:

*** Keywords ***
# Reported when Robot Framework version is below 6.1
Log In As ${user}
    [Arguments]    ${password}
    Log    ${user}:${password}

# Valid from Robot Framework 6.1 and later
Create User ${name} In ${team}
    [Arguments]    ${role}
    Log    ${name} / ${team} / ${role}

The problem is highlighted on the affected user keyword statement so you can either split argument styles or update the Robot Framework version used by the project.
