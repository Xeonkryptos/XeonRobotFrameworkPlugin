Reports variable type conversion definitions when the configured Robot Framework version does not support this syntax.

Declaring an expected data type directly on a variable, such as ${name: int}, was introduced in Robot Framework 7.3. This inspection flags such declarations when the project's Robot Framework version is set to an earlier version, helping you avoid parsing errors at runtime.

Example:

*** Keywords ***
Example Keyword
    [Arguments]    ${count: int}
    ${values: list[int]} =    Create List    1    2    3

This is only reported when the project's Robot Framework version is below 7.3; on 7.3 and later, the same declarations are valid.

The problem is highlighted on the affected variable declaration so you can either remove the type conversion definition or update the Robot Framework version used by the project.
