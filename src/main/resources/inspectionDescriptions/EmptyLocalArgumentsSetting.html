Reports an [Arguments] setting inside a keyword that does not declare any argument.

An [Arguments] setting without any argument does not change how the keyword can be called, so it only adds noise without providing any value.

Example:


*** Keywords ***
My Keyword
    [Arguments]    # no argument declared -> will be marked as empty
    Log    Hello World

Text after this comment will only be shown in the settings of the inspection.

Removing the empty setting keeps keyword definitions concise and makes it immediately clear which keywords actually declare arguments.
